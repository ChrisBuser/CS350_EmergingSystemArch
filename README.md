# CS350_EmergingSystemArch


## Summarize the project and what problem it was solving.

The final project is a prototype of a smart thermostat. This is used to showcase the abilities of an embedded system and simulate connection to the cloud to meet IoT requirements for the client. 

## What did you do particularly well?

I believe that I did a good job of keeping the code as clean as possible and using best practices where appropriate. Specifically, in the Milestone3.py file, within the transmit() method I am proud of my implementation of iterating the message and calling the correct transitions. My use of case statements rather than conditionals is the preferred method. 

## Where could you improve?

I have plenty of room for improvement with threading. I am aware that in some cases the order of events can potentially take place out of the correct sequence. This could have massive consequences in embedded devices. 

## What tools and/or resources are you adding to your support network?

The Raspberry Pi will be an excellent tool to continue developing my skills. This hardware provides a great opportunity to be creative and work on additional projects. I have begun to brainstorm other projects I can use these tools for to showcase my abilities for future employers. 

## What skills from this project will be particularly transferable to other projects and/or course work?

Through this course, I have become more comfortable in finding the information I need in the documentation for various libraries. Where I would previously use a search engine for my questions, I will now carefully review documentation sites for understanding. 

## How did you make this project maintainable, readable, and adaptable?

I made every effort in the project to keep the code very dry. By this, I mean that I aimed to keep logic in one place and use that for various other methods. By doing this, the project can be maintained in one location rather than several. If not performed this way, I would be welcoming bugs in the future since it would be difficult for the next person to maintain it.
